복지틈새찾기 API 수집 확대 수정파일

적용 방법
1. ZIP을 풀고 파일 경로를 유지한 채 기존 저장소 폴더에 덮어씁니다.
2. GitHub Desktop에서 변경 내용을 확인하고 main에 커밋/Push 합니다.
3. GitHub 저장소 Actions에서 Weekly welfare API sync를 Run workflow로 실행합니다.
4. 수집/검증 단계가 완료된 뒤 Pages를 새로고침하고 화면의 데이터 수집 시각과 건수를 확인합니다.

인증키는 채팅이나 HTML에 넣지 마세요. 저장소 Settings > Secrets and variables > Actions에 둡니다. 기존 WELFARE_API_KEY를 지자체 수집에 쓰고, 중앙부처 API에도 승인된 키면 별도 키 없이 재사용합니다. 별도 키인 경우 CENTRAL_WELFARE_API_KEY를 추가합니다.

이 수정은 Actions에서 더 넓은 API 목록을 수집합니다. 검색 시점마다 API를 직접 호출하는 구조로 바꾸지는 않습니다.
