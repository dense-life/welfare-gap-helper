복지틈새찾기

내 생활 상황을 바탕으로 놓치고 있을지 모르는 복지 지원을 찾아보고, 무엇을 더 확인해야 하는지 정리해 드립니다.

꼭 확인해 주세요. 이 도구는 복지 후보를 찾아보는 안내용 시제품이며 정부의 자격 판정 서비스가 아닙니다. 최종 자격·금액·신청 가능 여부는 담당 기관에서 확인해야 합니다. 민감한 개인정보나 주민등록번호는 입력하지 마세요.

1. 생활 상황을 입력해 주세요

모르는 항목은 ‘모름/해당 없음’을 선택해도 됩니다. 입력 내용은 이 페이지 안에서만 비교하며 서버로 전송하지 않습니다.

해당하는 상황을 모두 선택해 주세요

입력 후 버튼을 누르면 관련 복지 후보가 표시됩니다.

2. 확인해 볼 복지 후보

상황을 입력하면 후보가 표시됩니다.
아직 조건을 분석하지 않았습니다. 위에서 조건을 입력하고 버튼을 눌러 주세요. 버튼이 작동하지 않으면 파일을 내려받아 Chrome에서 직접 여세요.

이용 팁: 결과가 없거나 조건을 잘 모른다면 주민센터 또는 보건복지상담센터(129)에 현재 상황을 설명하고 추가 상담을 요청하세요.

3. 공식 확인처

• 복지로 — 복지서비스 검색·모의계산·복지멤버십 안내

• 정부24 — 정부 서비스·민원 안내

• 보조금통합포털 — 보조금 정보 확인

• 공공데이터포털 — 공식 데이터·API 확인

• 보건복지상담센터 129 — 복지 상담

데이터 상태: 기본 공식 안내 후보 + GitHub Actions가 갱신한 지자체 API 후보. API 데이터 갱신은 저장소에 인증키를 설정한 뒤 활성화됩니다.

공식 데이터 연동 준비: 공공데이터포털에서 복지서비스·보조금 API 검색 및 활용신청 · 보조금통합포털 오픈API 안내. API 인증키는 공개 HTML에 넣지 마세요.
